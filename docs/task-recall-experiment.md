# DSH 任务相关召回：指针实验

状态：默认关闭。当前是低覆盖、高门槛的词面候选实验，不是语义重排、记忆权限或跨会话推理能力的升级。

## 启用范围

仅在本机单用户、允许模型接收候选编号的测试会话中启用。为 `dsh-lm-memory` 的现有配置增加：

```yaml
taskRecall:
  enabled: true
  sessionIds:
    - session-替换为测试会话的准确ID
```

删除配置或设置 `enabled: false` 即可关闭。不要配置通配符（实现只认精确 ID）。插件与 `memory_recall` 必须指向同一个测试库；不要在多人共用库、跨项目权限未隔离、或不同 Agent 应当看见不同库的场景启用。这几项配置不是数据库访问控制。设置 `allowRemote: false` 时不注册实验钩子。候选检索自身不联网；候选编号是宿主上下文的一部分，可能进入会话日志及宿主的模型请求。关闭实验不会追溯删除已记录的消息。

## 候选规则

- 每次最多解读一条、确实被宿主接纳的真人纯文本消息。忽略系统注入、批量输入、附件及过长文本；跳过已知凭据模式和明确的退出语句。凭据检测不涵盖所有敏感信息。
- 问句须包含回溯信号，并具备一个带引号的字面锚点，如 `上次「部署验收」怎么做？`，或两个独立 ASCII 字面锚点，如 `上次 lm-memory Viewer 配置什么端口？`。无泛搜兜底，不会搜到所有相关问题。
- 用隔离 Worker 只读查询现有 SQLite FTS5 内容索引，只在恰有一条 `active` 的事实、偏好或经验匹配时提示。索引未就绪、资源已占用、查询异常、取消或达到 200ms 等待上限时继续原请求，不排队、不重试。不加载模型、不写入曝光或续租数据、不启动摄入，不主动唤醒记忆；SQLite WAL 读取仍需操作系统允许访问数据库的辅助文件。
- 每次最多注入一个候选编号，上限 512 UTF-8 字节，不注入记忆正文或被匹配的用户文本。只在当前有效时由 Agent 按编号调用工具核对。候选指针不是事实、权限变化或使用反馈；工具调用在原有 MCP 路径上执行。活跃会话内去重，不对宿主重启、日志重放后的去重作保证。

## 已验收的接线

- `node --test tests/task-recall.test.mjs`：用临时库验证状态过滤、唯一匹配、会话白名单、超时、预算和不续租。
- 从安装版 DSH 环境运行 `node scripts/eval/dsh-headless-memory-smoke.mjs`：另建临时 HOME/DSH_HOME，通过 loopback 模型协议桩实测默认不发提示、同一 Session 跨进程恢复后发出批准范围内的一个编号、不发匹配正文、续聊产生新的用户采集卡（候选提示不参与采集）、其他 Session 无提示。此探针验证 macOS 上已安装的 Headless 链路，不验证 Desktop GUI、Windows 或模型答题质量。

## 下一步验收

在冻结、脱敏的一批真实任务上，分别跑关闭实验与启用实验：答案质量、候选命中和误提示、候选后续工具使用率、额外模型调用量及上下文负担。至少包含有效/已纠正/已删除/已休眠事实、毫不相关及含多条相似候选、字段有凭据、会话不在授权列表、只用中文且无引号等负例。样本应覆盖「模型应主动查」和「不该被旧记忆牵引」两类。保持读者、工具权限、固定测试库及 token 上限相同；另记录每次实际字节数和延迟。没有受控真实任务收益前不转默认打开。
