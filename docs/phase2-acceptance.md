# 第二轮改造与冻结验收

尚未宣称达到第二梯队。本轮不修改生产数据，不发布。

## 失败分析

上一轮多跳126道错题中116道未取齐标注证据；开放域56道错题中14道证据全齐仍答错。缺证据与reader能力分开统计。

## 当前实现

- 英文自然问句走独立词级BM25候选，处理停用词、标点与所有格；其余中文与词法/语义融合保持原路径。
- 长记忆增加384字符、64重叠的段向量；返回仍为完整父记录；删除父记录同步移除段向量；已有长条异步补嵌。字符窗降低截断影响，不宣称任意字符都严格对应固定token数。
- 真实双模型合成探针：945字符相同前缀、只改变末尾城市，两个模型的尾段向量均不同；原文与来源记录不切断。
- memory_batch_remember最多50条，逐条走统一提交防线与事务，批末刷新派生视图。批次不承诺全有或全无。
- server/retrieval-plan.mjs为可复用多查询检索器，主问加最多3个子问，RRF合并去重，最终仍最多15条且16KiB，不能靠扩大读入预算制造提升。模型规划由宿主提供；目前实验runner已接入，真实DSH宿主尚未接入。
- reader推断提示为单独实验开关，不能将其收益归因为检索或记忆提升。
- 批量基准摄入关闭未参与答案检索的图谱构建，记录graph=false。生产默认不关闭图谱。

## 验收设计（在开发结果出来前冻结）

LoCoMo前三段、category1/3做四项消融：新检索；新检索+查询规划；新检索+reader推断；组合。与已留档的相同题逐项比较。

候选准入：弱项正确率至少提升3个百分点、多跳至少提升3个百分点、标注证据全齐率不得下降。未通过则拒绝，不在保留组上继续调参数。通过才把固定候选配置送入后七段全类别回归。

这10段LoCoMo已经在之前全量测过，后七段只是本轮冻结迭代回归组，不是全新未见的holdout，也不能单独证明泛化。

LongMemEval-S使用完整S数据（不是Oracle），先一题验证摄入和QA判分闭环，再500题。每题独立临时库，短重叠片段入库，主检索15条/16KiB，不额外注入全会话时间线。该协议不能与旧22题+全时间线0.55直接相减；需要分别报告。

用户指定同一glm-5.3-flash作reader与judge；这是分离调用，不是独立模型判分，须保留该偏差说明。

## 已有证据

本地15组套件通过，新增BM25、分段、批量防线与查询合并测试通过。真实双模型固定集Hit@5仍0.8387、证据完整0.8065、误召回条目占比0.5904，没有把功能上线当作分数提升。

远程阶段使用独立后台监督进程、原子检查点、源码哈希冻结、请求缓存与有限重试。产物位于本次工作目录remote-eval/phase2/。LongMemEval单题预检已通过，500题运行中；LoCoMo消融运行中。

## 尚未完成

真实DSH隔离生命周期；跨会话事实归一/纠正；语义改写后的防复活；图谱增量维护；完整版本化迁移；长期遗忘效果。远程分数也不能替代这些验收。

## 最终状态（2026-11-18）

LongMemEval-S完成500题，退出码0，310/500=62.0%。跨会话48/121=39.67%、时间75/127=59.06%、知识更新63/72=87.5%、弃答28/30=93.33%。不同于旧22题全时间线协议，不能将二者差值称为改进。

四项LoCoMo开发组消融全部未通过预先设定的门槛，因此未执行后七段候选验收。旧基线53/95=55.79%；新检索45/95=47.37%；加查询规划47/95=49.47%；加reader推断62/95=65.26%；全组合61/95=64.21%。后两者答案正确率提高，但证据全齐率下降，不能当作检索能力提升。

收尾审查发现实验英文词法分支的字符类有重复转义，部分英语问句未如预期进入词级BM25；因此这些结果只能评价留档哈希对应的实际实现，不能当作有效的BM25算法消融。已修正判断，但尚未重新验证修正后的BM25质量。

未通过质量门槛的两个检索变更现在默认关闭：LM_WORD_BM25=1启用实验词级BM25，LM_PASSAGE_SEARCH=1启用实验段向量。默认恢复原词法/语义路径，可靠性修复和批量写入保留。此前真实尾段探针证明可见性，未证明其整体召回收益。
